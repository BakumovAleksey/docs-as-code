# Data Sheet

## Общая информация

**Название датасета:** multilingual-NLI-26lang-2mil7 (основной
обучающий датасет модели) и XNLI (валидация)

**Источник:** Hugging Face Hub

**Назначение:** обучение мультиязычной NLI-модели, применимой для
zero-shot классификации, в том числе категорий обращений.

## Состав данных

**Объём:** 2 730 000 пар «гипотеза–посылка» на 26 языках (105 000 пар
на язык; для английского добавлена дополнительная выборка).

**Тип данных:** текстовые пары «посылка–гипотеза» с меткой класса
(включение / нейтральность / противоречие).

**Основные поля / признаки:** посылка (premise), гипотеза (hypothesis),
метка. Русский язык входит в список языков датасета.

XNLI (валидация): 2490 профессионально переведённых текстов на 15 языках.

## Получение данных

Датасет создан на основе англоязычных наборов MultiNLI, Fever-NLI,
ANLI, LingNLI и WANLI, переведённых на 26 языков с помощью моделей
машинного перевода.

## Предобработка

Точная предобработка авторами не описана; указано, что данные получены
машинным переводом англоязычных наборов.

## Ограничения

- качество данных ограничено качеством машинного перевода;
- тематика исходных наборов (бытовые тексты, события, статьи) не
  совпадает с тематикой обращений в поддержку;
- в исходных данных NLI отсутствуют категории обращений — модель
  работает с ними только в режиме zero-shot.

## Использование в проекте

Датасет определяет способность модели сопоставлять текст обращения с
произвольными категориями без дообучения. Для оценки качества
классификации категорий в проекте необходима отдельная тестовая
выборка из размеченных обращений.
