# Классификатор обращений

Сервис автоматически определяет категорию обращения пользователя
и направляет его соответствующей группе технической поддержки.

Основные пользователи:
- пользователь;
- оператор поддержки.

Основные функции:
- отправка обращения;
- определение категории обращения;
- просмотр результата классификации.

## Комплект документации

1. **Описание проекта** — для всех, чтобы понять назначение сервиса.
2. **Требования** — для разработчиков и тестировщиков, чтобы понять, что должна делать система.
3. **Архитектура системы** — для разработчиков, чтобы понять структуру компонентов.
4. **Документация API** — для разработчиков интеграций, чтобы использовать эндпоинты.
5. **Документация ML-модели** — для ML-инженеров, чтобы описать данные и метрики модели.
6. **Руководство пользователя** — для операторов, чтобы объяснить, как пользоваться сервисом.
