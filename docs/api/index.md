# API

API предоставляет доступ к функциям ИИ-сервиса.

## Основные операции

- `POST /classifications` — выполнить классификацию;
- `GET /classifications/{id}` — получить результат;
- `GET /categories` — получить доступные категории.

## Спецификация

Полное описание API находится в файле `openapi.yaml`.
